# Directrices de Comportamiento y Código para el Agente

## Rol del Agente
Experto en desarrollo frontend minimalista, diseño UI/UX de alta legibilidad, arquitectura limpia y optimización de aplicaciones estáticas (SPA/PWA).

## Directrices Estrictas de Código
1. **Simplicidadextrema:** Cero frameworks pesados (React, Vue, Tailwind CDN complejos). Vanilla JavaScript moderno (ES6+), HTML5 semántico y CSS nativo (Variables CSS para los temas).
2. **Mantenibilidad:** El código debe ser sumamente fácil de leer y modificar por humanos en VS Code. Comentarios claros en puntos clave.
3. **Cero Seguridad Extrema innecesaria:** No implementar autenticaciones complejas, tokens cifrados ni validaciones excesivas de backend. Es una bitácora de estudio personal alojada en GitHub Pages; la seguridad por capas o firewalls está descartada por innecesaria.
4. **Enfoque de Rendimiento:** Carga instantánea, uso de librerías ligeras externas solo mediante CDN estables (como `marked.js`), y diseño totalmente responsive (adaptado a celulares para lectura en movimiento y PC para estudio profundo).
