# Misión y Visión del Portal de Estudio

## Misión
Proveer una plataforma web minimalista, ultrarrápida, modular y multiplataforma orientada al autoestudio intensivo. Permitir la documentación y lectura fluida de lecciones organizadas por materias (como Latín, Programación, etc.), utilizando un flujo de trabajo basado en archivos Markdown editados localmente y publicados mediante GitHub Pages, sin fricciones de bases de datos ni arquitecturas innecesariamente complejas.

## Visión
Convertirse en el cuaderno digital definitivo del estudiante moderno: accesible desde cualquier dispositivo (celular, tablet o PC gracias a su soporte PWA), con identidades visuales adaptadas e inmersivas para cada disciplina (estética clásica/histórica para humanidades, estética hacker/terminal para tecnología), garantizando control absoluto de los datos y disponibilidad offline.
